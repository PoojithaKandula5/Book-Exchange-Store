# 📚 Book Exchange Platform
A web-based platform for exchanging books, connecting readers, and chatting with other users. Built using **Flask**, **MongoDB**, and **Bootstrap**, this project supports authentication, book management, user/admin dashboards, and a real-time-style chat system.



## 🚀 Features

### 🔐 User Authentication
- Register, login, and logout functionality  
- Secure password hashing using Werkzeug  
- Session handling for user login state  

### 📖 Book Management
- Add, view, edit, and delete books  
- Upload book images  
- Store book details in MongoDB  

### 👤 User Dashboard
- View user’s own books  
- Manage added books  
- Browse available books from others  

### 🛠 Admin Dashboard
- View all registered users  
- View all books uploaded on the platform  
- Manage community activity  

### 💬 Chat System
- Send and receive messages between users  
- Track unread messages  
- Inbox and chat interface  

### 🎨 Responsive UI
- Clean and mobile-friendly design  
- Built with **Bootstrap**
